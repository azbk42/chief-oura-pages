Chief Personal Monitoring

Chief is a local-first private personal performance monitoring application for its owner. It organizes daily habits, sleep, recovery, physical activity, and performance journals.

Oura Integration

With the owner's authorization via Oura OAuth, Chief can access permitted Oura sleep, readiness, activity and recovery data and store them locally for personal day-by-day history and monitoring.

This informational website does not collect Oura data or host the Chief app.
